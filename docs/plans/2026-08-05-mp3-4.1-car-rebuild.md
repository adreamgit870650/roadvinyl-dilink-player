# MP3 播放器 4.1 车机重构计划

## 目标

在保留现有歌单、收藏、扫描目录、歌词与播放进度数据的前提下，解决长时间播放后方向盘媒体键失效，并把播放器重构为适合横屏车机、行驶中可快速识别和盲操作的界面；增加应用内检查和安装更新。

## 设计原则

- 播放页优先：打开即看到当前歌曲、歌词、进度和大尺寸控制。
- 车机优先：主要触控目标不小于 56dp；高频控制不藏在二级菜单。
- 夜间优先：低亮深色背景、单一暖橙强调色、文字保持高对比。
- 横屏优先：封面/黑胶与歌词并列，控制区固定；竖屏保留完整可用。
- 克制动效：只保留唱片旋转、状态切换和页面转场，不做驾驶中干扰视线的装饰动画。
- 数据不迁移：继续使用原包名和现有 SharedPreferences、数据库与本地文件路径。

## 实施

1. 建立长期播放方控健康策略和回归测试。
2. 将播放服务迁移到可被系统持续发现的 MediaSessionService。
3. 去除逐句歌词对 MediaItem 时间线的频繁替换；按歌曲更新会话元数据。
4. 加入媒体会话/媒体键接收器自愈心跳和服务存活诊断。
5. 重做播放页、曲库页、导航和设置页的信息层级与触控尺寸。
6. 增加腾讯云版本检查、APK 下载、校验和系统安装流程。
7. 更新 GitHub Actions，使每次构建同时产出可发布 APK 和校验值。
8. 编译、静态检查、自动化测试、生产下载校验与车机验收清单。

## 验收

- 连续播放期间，会话可被系统控制器发现；媒体键路由丢失后能够自动恢复。
- 上一首、下一首、播放/暂停在应用前台、后台和熄屏恢复后都走同一播放服务。
- 歌词滚动不会每行替换 MediaItem。
- 横屏首屏无需滚动即可操作上一首、播放/暂停、下一首、模式与进度。
- 设置页可检查新版本、下载并拉起系统安装器；下载失败不会影响当前版本。
- 旧歌单、收藏、扫描路径、歌词和播放进度不被清空或改名。
